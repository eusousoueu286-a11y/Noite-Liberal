🌙 Noite-Liberal

Um espaço para casais liberais se conhecerem, conversarem e compartilharem experiências com respeito e privacidade.

💜 Sobre o projeto

O Noite-Liberal é um projeto de site voltado a pessoas adultas interessadas no estilo de vida liberal e swing. A proposta é facilitar novas amizades, conversas e a possibilidade de encontros presenciais consensuais.

✨ Objetivos

- Promover conversas respeitosas entre adultos.
- Facilitar o contato entre pessoas com interesses em comum.
- Incentivar o consentimento e os limites individuais.
- Valorizar a privacidade e a segurança dos participantes.

🛠️ Tecnologias

- HTML e CSS
- JavaScript
- GitHub Pages para hospedagem estática
- Supabase para recursos de autenticação e banco de dados, quando configurados

🔐 Segurança e privacidade

O projeto deve ser utilizado exclusivamente por adultos. O consentimento é indispensável em qualquer interação. Não publique fotos, dados pessoais ou informações de terceiros sem autorização.

Importante: a publicação do site não significa que todos os recursos estejam funcionando ou que a segurança esteja validada. A autenticação, as permissões do banco de dados e as políticas de privacidade precisam ser verificadas antes de disponibilizar o serviço ao público.

🚧 Estado do projeto

Em desenvolvimento. Os recursos disponíveis dependem da implementação e da configuração do projeto.
